# Auskraft — страница поддержки приложений

Статический сайт для GitHub Pages с каталогом приложений, целями поддержки и публичной офертой.

## Публикация

Сайт публикуется из корня ветки `main` через GitHub Pages.

На `auskraft.ru/support-apps/` платёжная кнопка и QR читают тот же публичный `payment-settings.json` из GitHub Pages. В Pages CMS пункт «Адрес страницы поддержки» выбирает, открывает ли постоянная ссылка `support-go.html` основной домен или GitHub Pages. Пункт «Баннеры обновления приложений» настраивает показ по целочисленному `versionCode` для каждого приложения. Включайте баннер после публикации выбранной версии в RuStore.

## Каталог приложений

Страница `catalog.html` берёт описания и историю версий из `catalog-data.js`. Выпуски каждого приложения перечислены от нового к старым. Чтобы подключить скачивание, укажите публичную ссылку на файл .apk с Яндекс Диска в поле `apkUrl` соответствующей версии. При значении `null` на месте ссылки появляется сообщение о недоступности файла. Ссылка на карточку в RuStore задаётся в `storeUrl` и отображается рядом с описанием приложения.

## Управление кнопкой поддержки

1. Откройте [настройки поддержки в Pages CMS](https://app.pagescms.org/Auskraft/apps-support/main/file/payment) и войдите через GitHub. При первой установке Pages CMS выберите репозиторий `Auskraft/apps-support`.
2. Заполните поле нужного сервиса действующей публичной ссылкой. Выберите CloudTips, Ozon Банк, GoDonate или ЮKassa и сохраните форму.
3. После публикации GitHub Pages проверьте кнопку на сайте. Обе кнопки открывают [постоянный адрес для поддержки](https://auskraft.github.io/apps-support/payment.html). При каждом открытии он читает выбранный сервис из [payment-settings.json](payment-settings.json). Этот же адрес можно использовать в приложениях на Flutter и Kotlin.

На сайте есть готовые QR-коды для настроенных ссылок CloudTips, Ozon Банка и GoDonate. При загрузке страницы отображается код выбранного сервиса, если его адрес совпадает с адресом в QR. Код ведёт прямо на страницу сервиса. Для остальных ссылок доступна кнопка поддержки.

В репозитории хранятся только публичные ссылки. Ключи платёжных API для этой схемы не нужны. Для смены сервиса проверьте, что описание перевода, возврата и обработки данных в [оферте](offer.html) соответствует выбранному сервису.

Сумму перевода выбирает отправитель. Налоговую квалификацию добровольных переводов и порядок оформления подтверждающих документов нужно определять с учётом применяемого налогового режима.
