# Auskraft — страница поддержки приложений

Статический сайт для GitHub Pages с каталогом приложений, целями поддержки и публичной офертой.

## Публикация

Сайт публикуется из корня ветки `main` через GitHub Pages.

## Robokassa

Кнопка «Поддержать» и QR-код ведут на одну платёжную страницу Robokassa с вводом суммы от 100 ₽. Налоговую квалификацию добровольных переводов и порядок формирования чека НПД нужно отдельно уточнить у специалиста или ФНС.
